Design System

A unified design language synthesized from Resume-Matcher (srbhr), Abdul Talha's Resume Parser, and Open Resume — optimised for clarity, trust, and speed.

May 2026 Inspired by 3 open-source projects React + Tailwind WCAG AA

Design synthesis rationale

Resume-Matcher uses a deep navy/indigo dark-tech tone with bold personality copy and a Next.js frontend (#1d4ed8 brand blue, Astro-built landing). Abdul Talha's project takes a data-first, structured approach — clean tables, minimal chrome. Open Resume is famously minimal: white-dominant, Inter typography, generous whitespace, blue-accent system. Synthesising all three: we get a light-first, indigo-accented system with high information density on results screens, generous breathing room on onboarding, and a slightly bold personality that doesn't take itself too seriously.

08 Voice, tone & copywriting rules
Personality spectrum
Borrowed from Resume-Matcher's playful boldness — not stuffy, not silly. Direct and confident. Empathetic to job seekers, efficient for HR. Never condescending. Always clear over clever.
Do / don't examples
✓ "Missing 3 required skills."
✗ "Unfortunately we were unable to detect the required skills."
✓ "Strong match. Go apply."
✗ "Your candidate profile is highly compatible."
Empty states
Friendly and action-oriented. "No resumes yet — drop one above to start." Never "No data found." Always suggest the next step.
